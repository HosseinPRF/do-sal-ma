# دو سال، یک دنیا ما ♡

یک PWA فارسی، راست‌به‌چپ، آفلاین و موبایل‌فرست برای دومین سالگرد؛ بازی دونفرهٔ پرسش و مأموریت با ۱۴۰ کارت اورجینال.

## امکانات

- چهار فصل داستانی: یخ‌ها آب می‌شن، ماشین زمانِ ما، حرف‌های ناتمام، فصل بعدی عشق
- هفت دسته کارت: فان، حدس‌زدن، خاطره، عاشقانه، آینده، مأموریت و صمیمی ۱۸+
- حالت‌های ۲۴، ۴۰ یا ۶۰ کارتی؛ کارت‌های تصادفی و بدون تکرار در هر بازی
- امتیاز جداگانه برای حدس‌های درست، «قلب‌های مشترک» برای مأموریت‌ها
- ذخیرهٔ خودکار پیشرفت و محبوب‌ها در مرورگر (localStorage)
- نامهٔ پایان بازی برای آرزوهای سال سوم، با قابلیت کپی و بدون ذخیرهٔ متن آرزوها
- بخش ۱۸+ فقط با فعال‌کردن اختیاری و تأیید سن و رضایت هر دو نفر
- نصب مثل اپ روی گوشی و استفادهٔ آفلاین پس از اولین بازدید آنلاین
- بدون سرور، ردیابی، کوکی تبلیغاتی، حساب کاربری یا بک‌اند

## انتشار رایگان در GitHub Pages

1. در GitHub یک **repository جدید Public** بسازید، مثلاً `do-sal-ma`.
2. تمام **محتویات این پوشه** را در ریشهٔ repository آپلود کنید. دقت کنید `index.html` باید در ریشه باشد، نه داخل یک زیرپوشه.
3. در repository وارد **Settings → Pages** شوید.
4. بخش **Build and deployment** را روی **Deploy from a branch** قرار دهید. شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.
5. پس از انتشار، نشانی برنامه تقریباً به شکل زیر است:

   `https://YOUR-USERNAME.github.io/do-sal-ma/`

   نام کاربری GitHub را جایگزین `YOUR-USERNAME` کنید. اگر نام repository را عوض کنید، بخش پایانی نشانی هم عوض می‌شود.

## نصب روی گوشی

- **Android / Chrome**: سایت را باز کنید → منوی سه‌نقطه → «Install app» یا «Add to Home screen».
- **iPhone / Safari**: سایت را باز کنید → Share → «Add to Home Screen».

ممکن است نوع دکمهٔ نصب به نسخهٔ مرورگر و سیستم‌عامل بستگی داشته باشد. برای نصب PWA، URL باید HTTPS باشد؛ GitHub Pages به صورت پیش‌فرض HTTPS ارائه می‌دهد. یک بار سایت را آنلاین باز کنید تا فایل‌های اصلی برای استفادهٔ آفلاین ذخیره شوند.

## اجرای محلی

می‌توانید `index.html` را مستقیم باز کنید (ولی نصب و Service Worker روی `file://` فعال نمی‌شود). یا در همین پوشه:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

## شخصی‌سازی

- **متن کارت‌ها** در `cards.js` است و به‌راحتی می‌توانید سؤال‌هایی با خاطرات و اسم‌های واقعی خودتان اضافه کنید. هر کارت باید `id` یکتا داشته باشد.
- **رنگ‌ها و سبک** در ابتدای `styles.css` تعریف شده‌اند.
- **عنوان و متن‌های صفحه** در `index.html` قرار دارند.
- **نام و تنظیمات بازی** موقع شروع قابل تغییرند.
- **کش آفلاین** در `sw.js` تعریف شده. اگر بعد از انتشار تغییراتی دادید و نسخهٔ قدیمی ماند، مقدار `CACHE` را از `do-sal-ma-v1` به `do-sal-ma-v2` (و همین‌طور بیشتر) تغییر دهید و دوباره منتشر کنید.

## حریم خصوصی و نکتهٔ مهم

نام دو بازیکن، ترتیب کارت‌های یک بازی، امتیازها و محبوب‌ها در فضای محلی همان مرورگر ذخیره می‌شود و به سایت یا سرور ارسال نمی‌شود. پاک کردن داده‌های سایت، وضعیت بازی را پاک می‌کند. متن آرزوهای آخر بازی فقط در فرم نگه داشته می‌شود و برای نگهداری باید از «کپی یادگاری امشب» استفاده کنید.

بخش بزرگسالانه شامل **پرسش‌های صمیمی و ملایم** است و محتوای صریح ندارد. فعال‌سازی آن کاملاً اختیاری‌ست و هر سؤال یا مأموریتی را می‌توان بدون توضیح رد کرد. تمام تماس‌های فیزیکیِ پیشنهادی مشروط به رضایت هر دو نفرند.

**این پروژه برای GitHub Pages نیازی به نصب پکیج، Node، npm یا build ندارد.**
