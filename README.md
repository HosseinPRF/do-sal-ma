# دو سال، یک دنیا ما — نسخهٔ دوم

بازی دونفرهٔ فارسی، مناسب گوشی، قابل نصب به صورت PWA. همهٔ کارت‌ها و فایل‌ها در همین پوشه‌اند؛ نیاز به سرور یا دیتابیس نیست.

## چی عوض شده؟

- **۳۶ کارت دست‌چین** در پنج دسته: کل‌کل و خنده (۸)، چقدر منو بلدی؟ (۸)، ماشین زمان (۷)، حرف دل (۷)، یه کار دونفره (۶).
- **۱۲ نوبت** در هر دور (۶ نوبت برای هر نفر). در هر نوبت یکی از پنج دسته را انتخاب کنید. می‌توانید کارت را عوض کنید یا سراغ دستهٔ دیگری بروید؛ کارت‌های دیده‌شده در همان دور تکرار نمی‌شوند.
- بعد از هر کارت نوبت جابه‌جا می‌شود. هر نفر هر سؤال یا مأموریتی را می‌تواند رد کند.
- در پایان می‌توانید چهار نوبت دیگر بازی کنید (حداکثر ۲۰ نوبت) یا یادگاری کوتاهی برای سال سوم بنویسید.
- بخش بزرگسالانه، فرم‌های اضافه، توضیح‌های طولانی و امتیاز رقابتی حذف شده‌اند. شمارش حدس‌های درست و مأموریت‌ها فقط برای سرگرمی است.

## انتشار در GitHub Pages

۱. یک Repository بسازید؛ تمام فایل‌های **داخل این پوشه** را در ریشهٔ مخزن بگذارید.
۲. در Settings → Pages بخش Build and deployment، گزینهٔ Deploy from a branch را انتخاب کنید؛ Branch را روی `main` و Folder را روی `/(root)` بگذارید.
۳. نشانی معمول: `https://USERNAME.github.io/REPOSITORY/`.
۴. برای نصب از موبایل، صفحه را در Safari باز کنید و Share → Add to Home Screen (آیفون) یا از منوی مرورگر Install app / Add to Home screen (اندروید) را انتخاب کنید.

**حریم خصوصی:** لینک GitHub Pages عموماً برای افراد دیگر هم قابل باز شدن است؛ گذاشتن Repository روی Private به تنهایی سایت Pages را خصوصی نمی‌کند. اطلاعاتی که در بازی تایپ می‌کنید، به سرور بازی ارسال نمی‌شود؛ نام‌ها، کارت‌های محبوب و وضعیت بازی فقط در حافظهٔ همان مرورگر ذخیره می‌شوند. کد سؤال‌ها در فایل `cards.js` قابل مشاهده است.

## تغییر کارت‌ها

فایل `cards.js` را با ویرایشگر متن باز کنید. هر کارت یک `id` یکتا، `type` و متن `q` دارد. دسته‌های قابل استفاده: `fun`, `guess`, `memory`, `romance`, `mission`. با هر تغییر، اگر برنامه نصب‌شده نسخهٔ قبل را نشان داد، یک بار در مرورگر صفحه را با اینترنت باز و رفرش کنید. برای تغییرات بزرگ، مقدار `CACHE` در `sw.js` را افزایش دهید.

## تست محلی

از همان پوشه یک وب‌سرور ساده اجرا کنید، مثلاً `python -m http.server 8000`، سپس صفحه را در `http://localhost:8000` باز کنید. برای نصب PWA در موبایل، هاست HTTPS نیاز است (GitHub Pages HTTPS ارائه می‌کند).
