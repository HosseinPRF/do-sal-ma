# دو سال، یک دنیا ما — نسخهٔ اصلاحی ۲.۱

این نسخه برای رفع مشکلات احتمالی بارگذاری جاوااسکریپت روی GitHub Pages آماده شده است. **تمام CSS، ۳۶ کارت و منطق بازی داخل `index.html` هستند** و دیگر فایل‌های `cards.js`، `app.js` یا `styles.css` لازم نیست. ظاهر و قوانین نسخهٔ دوم حفظ شده‌اند. نسخهٔ کش PWA هم ارتقا پیدا کرده است.

## انتشار جایگزین روی همان آدرس

۱. محتویات فایل ZIP را باز کنید و **فایل‌های داخل آن** را در ریشهٔ همان مخزن قبلی GitHub آپلود کنید (نه خود ZIP یا یک پوشهٔ اضافی).
۲. فایل‌های `index.html`، `sw.js`، `manifest.webmanifest` و پوشهٔ `icons/` باید دقیقاً در کنار هم قرار بگیرند.
۳. `Commit changes` را بزنید و در `Settings → Pages` انتشار شاخهٔ `main` / `(root)` را بررسی کنید.
۴. آدرس قبلی سایت تغییری نمی‌کند؛ پس از تکمیل انتشار، آن را در تب جدید باز و یک بار تازه‌سازی کنید. اگر نسخهٔ نصب‌شده روی گوشی هنوز قدیمی است، نسخهٔ جدید را در مرورگر باز کنید و دوباره اجرا کنید؛ در صورت نیاز سایت را از Home Screen حذف و دوباره اضافه کنید.
۵. فایل‌های قبلی `app.js`، `cards.js` و `styles.css` را اگر در مخزن باقی مانده‌اند، می‌توان بعداً حذف کرد؛ نسخهٔ جدید آن‌ها را بارگذاری نمی‌کند.

## بررسی سریع

اگر هنوز دکمه کار نمی‌کند، URL دقیق سایت را بررسی کنید و مطمئن شوید فایل `index.html` جدید در مسیر درست منتشر شده است. «View source» را باز کنید؛ انتهای سورس باید کد حاوی `window.LOVE_CARDS` داشته باشد. در `Developer Tools → Console` خطاهای قرمز را بررسی کنید.

بازی داده‌ها را فقط در حافظهٔ محلی مرورگر ذخیره می‌کند و از سمت سایت اطلاعاتی به سرور ارسال نمی‌کند. صفحهٔ GitHub Pages به صورت پیش‌فرض عمومی است.
